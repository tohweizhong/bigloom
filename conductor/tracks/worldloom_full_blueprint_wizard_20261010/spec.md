# Specification: Full WorldLoom Pack and Blueprint Configuration (`bigloom init`)

## Overview
Expand BigLoom's WorldLoom integration (`src/bigloom/wizard.py`, `src/bigloom/build.py`, `src/bigloom/proposal/spec.py`, `src/bigloom/proposal/facts.py`, and `src/bigloom/cli.py`) to support all WorldLoom company pack fields (`annual_revenue`, `employees`, `fiscal_year_start_month`, `headquarters`, `regions`, `seasonality`, `estate`, `landscape`, `name_pools`, `system_brands`, `voices`, and `lore`) as well as WorldLoom `Blueprint` dimensions (`locale` via `.located()`, `facets` via `.facets()`, and `estate`/`landscape` via `.estate()`). Ensure every custom pack generated by `bigloom init` passes `worldloom.packs.lint` with zero findings.

## Functional Requirements
1. **Lint-Clean Full WorldLoom Pack Builder (`src/bigloom/wizard.py`)**:
   - Expand `build_org_pack_dict` and `write_org_pack_json` to accept:
     - `annual_revenue` (int, default `1_700_000`)
     - `employees` (int, default `3_900`)
     - `fiscal_year_start_month` (int `1..12`, default `4`)
     - `headquarters` (str, default `"Mapletree Business City, Singapore"`)
     - `regions` (sequence of str, default `("Central", "East", "North", "North-East", "West")`)
     - `seasonality` (`"flat"`, `"christmas"`, or `"summer"`, default `"flat"`)
     - `estate` (`"small"`, `"medium"`, or `"large"`, default `"large"`)
     - `landscape` (`"retail"`, `"banking"`, `"insurance"`, or `"procurement"`, optional)
     - `given_names` and `surnames` (`name_pools`)
     - `system_brands` (`dict[str, str]`, default `erp`, `mdm`, `platform`, `commerce`, `pos`)
     - `cfo_voice` and `cfo_phrases` (`voices`)
     - `lore_assertion` (str, builds a valid `decision` and `norm` `lore` list targeting engine-consulted targets so `worldloom.packs.lint` returns `[]`).
2. **Blueprint Dimensions in `ProposalSpec`, `facts.py`, and `build.py`**:
   - Add optional fields `locale: str | None = None` and `facets: dict[str, str] = Field(default_factory=dict)` to `ProposalSpec` in `src/bigloom/proposal/spec.py`.
   - Update `_load_world` in `src/bigloom/proposal/facts.py` and `_resolve_world_context` in `src/bigloom/build.py` to apply `.located(locale)` and `.facets(**facets)` when constructing a WorldLoom `Blueprint`.
   - Expose `--locale` and `--facet` (comma-separated `key=value`) on `bigloom build` in `src/bigloom/cli.py`.
3. **Interactive Wizard Advanced Prompts (`bigloom init`)**:
   - In `run_interactive_wizard`, ask if the user wants to configure advanced WorldLoom blueprint options (`scale, geography, systems, facets, locale, lore`, default `False`).
   - When confirmed (`y`), prompt for:
     - Scale and calendar (`annual_revenue`, `employees`, `fiscal_year_start_month`, `seasonality`)
     - Geography and locale (`locale`, `headquarters`, `regions`)
     - Technology estate and system brands (`estate`, `erp` brand, `platform` brand)
     - People and executive voice (`given_names`, `surnames`, `cfo_voice`)
     - Company facets (`key=value` comma-separated, e.g. `listing=state_owned,scale=enterprise`)
     - Lore decision assertion
   - Validate generated `org-pack.json` with `worldloom.packs.lint` and include `"pack_lint_findings"` in the wizard summary.
4. **Documentation (`README.md`)**:
   - Document all WorldLoom pack fields, the seven company facets, locales, landscapes, and the advanced `bigloom init` prompts in `README.md`.

## Acceptance Criteria
- Every `org-pack.json` written by `write_org_pack_json` passes `worldloom.packs.lint(worldloom.packs.load(path))` with `[]` (0 findings).
- `bigloom init` supports both default and advanced WorldLoom blueprint prompts in `proposal` and `corpus` modes.
- `pytest --cov=src/bigloom` passes with >= 90% coverage and `ruff check .` passes with 0 errors.
